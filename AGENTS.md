# Moriyati website publishing policy

## User's standing instruction

For ordinary additions, removals, corrections, design changes, and other website
updates, implement and validate the requested change, then commit and push it to
the GitHub repository `moriyati-ir/moriyati.ir`. GitHub Pages is the working
preview. Keep the repository's existing GitHub Pages publication enabled.

Liara is reserved for final releases. Do not upload or deploy ordinary changes
to Liara, and do not enable automatic deployment from GitHub to Liara.

Update the Liara application `moriyati-ir` (the public `moriyati.ir` website)
only when the user explicitly requests a Liara update, for example:
"لیارا را آپدیت کن" or an equivalent explicit instruction. A request to change
the website, by itself, does not authorize a Liara deployment.

When a Liara update is explicitly requested, publish the latest intended and
validated GitHub version, then verify the live site. Read-only inspection of
Liara does not constitute deployment and remains permitted when relevant.

This policy was requested by the user on 2026-11-13 and supersedes any earlier
default of publishing each change to Liara.
